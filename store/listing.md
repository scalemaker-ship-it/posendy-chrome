- 요약(manifest description, 132자 이내): 포샌디 크롬 확장이에요. 네이버 블로그 발행을 내 크롬에서 처리하고, AI 앱이 내 크롬을 MCP로 쓸 수 있게 해요.
- 카테고리: 도구(Tools)
- 언어: 한국어
- 아이콘: `icon-128.png` (128x128, 투명 배경)

- 작은 프로모션 타일: `promo-tile-440x280.png`
- 홈페이지: https://posendy.com
- 지원: https://posendy.com/ko/guide/naver-extension (문의 help@posendy.com)
- 개인정보처리방침: https://posendy.com/ko/privacy

### 상세 설명

```
POSENDY Chrome은 포샌디(posendy.com) 사용자를 위한 크롬 확장이에요.

[네이버 블로그 발행]
네이버 블로그에는 공식 글쓰기 API가 없어서, 포샌디에서 보낸 글을 이 확장이 내 크롬에서 네이버 글쓰기 화면으로 올려요.
- 팝업에 포샌디 API 키를 넣으면 30초마다 발행 대기 글을 확인해요.
- 제목, 카테고리, 태그, 공개 범위(전체, 이웃, 비공개), 발행 또는 임시저장을 지정해요.
- 네이버 비밀번호를 묻거나 저장하지 않아요. 이미 로그인된 크롬의 네이버 세션을 써요.

[브라우저 MCP]
내 컴퓨터의 AI 앱(Claude Code 등)이 이 크롬을 도구로 쓰게 해요.
- 페이지 열기, 클릭, 입력, 읽기, 스크린샷 등 도구 43개
- 별도 작업 탭에서 실행해서 보고 있는 탭은 건드리지 않아요.
- 연결은 이 컴퓨터 안의 네이티브 메시징으로만 오가고, 이 기능으로 다룬 페이지 내용은 포샌디 서버로 보내지 않아요.
- 사용하려면 포샌디 연결 프로그램(브리지)을 설치해야 해요: https://posendy.com/ko/guide/chrome-mcp

설치 후 할 일과 문제 해결은 https://posendy.com/ko/guide/naver-extension 에 있어요.
```

## 2. 개인정보 보호 관행 (Privacy practices)

### 단일 목적 (Single purpose)

```
사용자가 연결한 도구(포샌디 서비스, 사용자 컴퓨터의 AI 앱)가 사용자 본인의 크롬에서 웹페이지 작업을 대신 수행하게 하는 브라우저 자동화. 대표 작업은 포샌디에서 요청한 글을 네이버 블로그 글쓰기 화면에 발행하는 것이다.
```

### 권한별 사용 이유 (Permission justification)

| 권한                     | 사용 이유                                                                                                                                                                              |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| nativeMessaging          | 사용자 컴퓨터에 설치한 포샌디 브리지와 통신해 AI 앱의 브라우저 작업 요청을 받고 결과를 돌려준다. 통신은 이 컴퓨터 안에서만 이뤄진다.                                                   |
| tabs                     | 작업할 탭을 만들고, 고르고, 주소와 제목을 읽어 작업 대상을 찾는다.                                                                                                                     |
| tabGroups                | 확장이 연 작업 탭을 "MCP" 탭 그룹으로 묶어 사용자가 구분할 수 있게 한다.                                                                                                               |
| activeTab                | 사용자가 확장을 누른 현재 탭에서 요소 선택 등 작업을 한다.                                                                                                                             |
| scripting                | 네이버 글쓰기 화면과 작업 탭에 스크립트를 넣어 입력, 클릭, 페이지 읽기를 한다.                                                                                                         |
| contextMenus             | 우클릭 메뉴에서 확장 기능(작업 패널 열기 등)을 실행한다.                                                                                                                               |
| downloads                | 사용자가 요청한 스크린샷과 파일을 다운로드 폴더에 저장하고 다운로드 완료를 확인한다.                                                                                                   |
| webRequest               | 작업 탭의 진행 중인 요청 수를 세어, 페이지 로딩이 끝난(네트워크가 조용해진) 뒤에 다음 단계를 실행한다. 요청 내용은 저장하거나 보내지 않는다.                                           |
| webNavigation            | 작업 탭의 페이지 이동 완료를 감지해 페이지가 준비된 뒤에 다음 단계를 실행한다.                                                                                                         |
| debugger                 | 크롬 DevTools 프로토콜로 정확한 클릭, 키 입력, 보이지 않는 탭의 스크린샷, 성능 기록을 수행한다. 작업 탭에만 연결한다.                                                                  |
| history                  | AI 앱이 요청할 때 방문 기록을 검색해 돌려준다(사용자 요청 시에만, 이 컴퓨터 안에서만).                                                                                                 |
| bookmarks                | AI 앱이 요청할 때 북마크를 검색, 추가, 삭제한다.                                                                                                                                       |
| offscreen                | 페이지 내용 검색에 쓰는 계산 작업(Web Worker)을 오프스크린 문서에서 돌린다(reason: WORKERS).                                                                                           |
| storage                  | 포샌디 API 키, 설정값(포트, 백그라운드 작업 등), 마지막 작업 결과를 확장 저장소에 보관한다.                                                                                            |
| declarativeNetRequest    | AI 앱이 요청할 때 작업 탭에 한해 특정 요청 차단, 헤더 변경 규칙을 세션 동안만 적용한다(updateSessionRules).                                                                            |
| alarms                   | 30초마다 포샌디 발행 대기 글을 확인하고, 예약된 작업을 정해진 시각에 실행한다.                                                                                                         |
| sidePanel                | 매일 작업과 작업 기록을 보여 주는 사이드패널을 연다.                                                                                                                                   |
| contentSettings          | 사용자가 확인 창에서 허용한 사이트에 한해 카메라, 마이크, 위치 같은 사이트 권한을 그 사이트(origin)에만 설정한다. 모든 사이트 일괄 변경은 기본으로 꺼져 있고 사용자가 켜야만 동작한다. |
| cookies                  | AI 앱이 요청할 때 지정한 사이트의 쿠키를 읽거나 설정한다(예: 로그인 상태 확인). 포샌디 서버로 보내지 않는다.                                                                           |
| notifications            | 발행 완료, 실패, 로그인 필요를 사용자에게 알린다.                                                                                                                                      |
| 호스트 권한 `<all_urls>` | AI 앱이 사용자가 지정한 어떤 사이트에서든 페이지를 읽고 조작할 수 있어야 한다. 네이버 발행은 blog.naver.com 에서만 동작한다.                                                           |

### 원격 코드 (Remote code)

### 데이터 사용 (Data usage) 체크 항목

- 인증 정보: 예 (사용자가 넣은 포샌디 API 키를 확장 저장소에 보관하고 posendy.com 에 보낸다)
- 웹 기록: 예 (사용자가 AI 앱으로 요청할 때만 읽고, 이 컴퓨터 안의 AI 앱으로만 보낸다)
- 웹사이트 콘텐츠: 예 (작업 탭의 페이지 내용을 사용자 컴퓨터의 AI 앱으로 보낸다. 네이버 발행 결과 글 주소를 포샌디로 보낸다)
- 사용자 활동: 예 (AI 앱이 요청할 때 작업 탭의 네트워크 요청을 기록하는 도구가 있음)
- 그 외(개인 식별 정보, 건강, 금융, 위치, 개인 통신): 아니요

- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않음
